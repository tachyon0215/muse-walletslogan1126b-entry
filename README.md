# muse-walletslogan1126b-entry

Entry for the make.fun competition [One-Line Slogan for a Solana Wallet Agent](https://make.fun/bounty/u-phudinhvfx-one-line-slogan-for-a-solana-wallet-agent-a7f6564e).

## The entry

> Your keys stay yours, your agent does the legwork: a Solana wallet that works while you sleep.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: it leads with ownership - the wallet category's core anxiety - then names the automation benefit (the agent does the legwork), and lands on the sleep image; the alternatives were either vague about the product or leaned on a borrowed meme line.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt`.
